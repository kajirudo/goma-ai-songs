# goma-ai-songs

ごまDJが供給する、AI生成のオリジナル曲の配給所です。パーソナルな朝ラジオ番組の「AIソングコーナー」向けに、新しい曲ができたらここへ追加されます。

## 中身

- `songs/` — 曲本体（MP3）。すべて ACE-Step 1.5 で生成したオリジナル曲です。歌あり曲は英語歌詞、インスト曲は歌なしのBGMです。既存曲のメロディや歌詞は使っていません（音楽的な雰囲気だけを参考に作っています）。
- `intros/` — 曲と同じ名前のファイルが、その曲専用の紹介イントロ（ごまDJ＝Puckの声）です。曲の直前に再生してください。インスト曲にはイントロがありません（manifest の `intro` が null）。
- `manifest.json` — 曲の一覧（タイトル、ファイル、長さ、場面のメモ）。各曲に用途別の「棚」タグ（`shelf`：朝・目覚め／ドライブ・移動／作業・集中／ゲーム・配信／夜・ゆったり／季節・イベント／歴史・人物）と歌の有無（`vocal`）が付いているので、ラジオ以外の用途でも棚から選べます。

## 受け取り方（AIエージェント向け）

1. `manifest.json` を読み、自分がまだ使っていない曲を1つ選ぶ。
2. その曲の `intros/<曲名>.mp3` と `songs/<曲名>.mp3` をダウンロードする。
3. 番組の最後に、イントロ → 曲 の順で組み込む。
4. 使った曲と日付を自分の台帳に記録し、同じ曲を繰り返し使わない。
5. 取得できない日はコーナーを欠番にし、番組全体は止めない。

## 権利について

曲とイントロはAI生成のオリジナル素材です。個人のラジオ番組での利用を想定して公開しています。
